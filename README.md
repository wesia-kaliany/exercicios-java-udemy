# Saida de Dados em Java

Projeto desenvolvido com o objetivo de aplicar na pratica os conceitos fundamentais de saida de dados em Java, utilizando como base os exercicios da secao de Estrutura Sequencial do curso "Java COMPLETO Programacao Orientada a Objetos".

# Aplicacao Pratica dos Conceitos

Neste projeto, foram implementadas rotinas em Java para exercitar:

- Impressao de textos simples com e sem quebra de linha utilizando `System.out.print` e `System.out.println`.
- Formataçao de valores numéricos e textos com `System.out.printf`, utilizando os especificadores de formataçao:
  - `%d` para numeros inteiros.
  - `%f` para numeros de ponto flutuante (delimitando casas decimais).
  - `%s` para textos (strings).
  - `%n` para quebra de linha padrao da plataforma.
- Modificacao do padrao de regionalizacao com a classe `Locale` (definindo o ponto como separador decimal em vez da virgula).
- Concatenacao de multiplas variaveis e textos em um unico comando de escrita.
